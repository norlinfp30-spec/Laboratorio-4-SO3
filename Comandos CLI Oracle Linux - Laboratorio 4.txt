🔴 PRÁCTICA 1 — Servidor HTTP Apache
En Oracle Linux (VM) — Todo desde cero
bash# 1. Actualizar el sistema
sudo dnf update -y

# 2. Instalar Apache
sudo dnf install httpd -y

# 3. Habilitar e iniciar Apache
sudo systemctl enable httpd
sudo systemctl start httpd

# 4. Abrir puertos 80 y 8080 en el firewall
sudo firewall-cmd --permanent --add-port=80/tcp
sudo firewall-cmd --permanent --add-port=8080/tcp
sudo firewall-cmd --reload

# 5. Verificar que Apache corre
sudo systemctl status httpd

# 6. Crear carpetas para los dos sitios web
sudo mkdir -p /var/www/holamundo
sudo mkdir -p /var/www/miperfil

# 7. Crear website 1 - Hola Mundo
sudo tee /var/www/holamundo/index.html << 'EOF'
<!DOCTYPE html>
<html>
<head><title>Hola Mundo</title></head>
<body>
<h1>Hola Mundo</h1>
</body>
</html>
EOF

# 8. Crear website 2 - Perfil personal
sudo tee /var/www/miperfil/index.html << 'EOF'
<!DOCTYPE html>
<html>
<head><title>Mi Perfil</title></head>
<body>
<h1>Nombre: Nolberto Francisco Perez</h1>
<h2>Matricula: 20252263</h2>
<h2>Materia: Sistemas Operativos 3</h2>
<h2>Docente: Adrian Alcantara</h2>
</body>
</html>
EOF

# 9. Crear Virtual Host para puerto 80 (Hola Mundo)
sudo tee /etc/httpd/conf.d/holamundo.conf << 'EOF'
<VirtualHost *:80>
    DocumentRoot /var/www/holamundo
    <Directory /var/www/holamundo>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
EOF

# 10. Agregar puerto 8080 a la configuracion de Apache
sudo tee -a /etc/httpd/conf/httpd.conf << 'EOF'
Listen 8080
EOF

# 11. Crear Virtual Host para puerto 8080 (Perfil)
sudo tee /etc/httpd/conf.d/miperfil.conf << 'EOF'
<VirtualHost *:8080>
    DocumentRoot /var/www/miperfil
    <Directory /var/www/miperfil>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>
EOF

# 12. Dar permisos correctos a las carpetas
sudo chown -R apache:apache /var/www/holamundo
sudo chown -R apache:apache /var/www/miperfil
sudo chmod -R 755 /var/www/holamundo
sudo chmod -R 755 /var/www/miperfil

# 13. Ajustar SELinux para las carpetas
sudo chcon -R -t httpd_sys_content_t /var/www/holamundo
sudo chcon -R -t httpd_sys_content_t /var/www/miperfil

# 14. Reiniciar Apache para aplicar cambios
sudo systemctl restart httpd

mydomain = rhel.com

mydestination = $myhostname, localhost.localdomain, localhost
inet_interfaces = all

🔴 PRÁCTICA 3 — Servidor de Impresión CUPS

Paso 1: Instalar CUPS y Repositorios (EPEL)
Como Oracle Linux 9 no tiene cups-pdf de forma nativa, habilitamos el repositorio EPEL.

Habilitar EPEL y CodeReady Builder:

Bash
sudo dnf install https://dl.fedoraproject.org/pub/epel/epel-release-latest-9.noarch.rpm -y
sudo dnf config-manager --set-enabled ol9_codeready_builder
Instalar CUPS y el cliente:

Bash
sudo dnf install cups cups-client -y
Habilitar y arrancar el servicio:

Bash
sudo systemctl enable cups --now
sudo systemctl start cups
Paso 2: Configurar Acceso Remoto
Editamos el archivo para que acepte conexiones de tu red.

Abrir el archivo:

Bash
sudo nano /etc/cups/cupsd.conf
Modificar/Asegurar estas líneas:

Apache
# Escuchar en todas las interfaces en el puerto 631
Port 631
Listen 0.0.0.0:631

# Permitir acceso general
<Location />
  Order allow,deny
  Allow 192.168.0.*
</Location>

# Permitir acceso a administración
<Location /admin>
  Order allow,deny
  Allow 192.168.0.*
</Location>

# Permitir configuración
<Location /admin/conf>
  AuthType Default
  Require user @SYSTEM
  Order allow,deny
  Allow 192.168.0.*
</Location>
Reiniciar el servicio:

Bash
sudo systemctl restart cups
Paso 3: Instalar Impresora Virtual PDF
Instalar el paquete:

Bash
sudo dnf install cups-pdf -y
Verificar que aparece en el sistema:

Bash
lpstat -p
Paso 4: Configurar Firewall
Permitimos el tráfico del servicio de impresión.

Bash
sudo firewall-cmd --add-port=631/tcp --permanent
sudo firewall-cmd --add-service=ipp --permanent
sudo firewall-cmd --reload
Paso 5: Configuración en la Web de CUPS
Entra desde tu navegador a: http://192.168.0.199:631

Ve a Administration -> Add Printer (Usa tu usuario nolberto y tu contraseña).

Selecciona CUPS-PDF (Virtual PDF Printer).

IMPORTANTE: En la siguiente pantalla, marca la casilla "Share This Printer".

En Fabricante, selecciona Generic. En Modelo, busca Generic CUPS-PDF Printer (en).

Dale a Add Printer.

Paso 6: Instalación en Windows 11 (Método IPP)

En Windows, ve a Impresoras y escáneres -> Agregar dispositivo -> Agregar manualmente.

Selecciona: "Seleccionar una impresora compartida por nombre".

Escribe la URL exacta:
http://192.168.0.199:631/printers/Virtual_PDF_Printer

Dale a Siguiente. Si te pide un controlador, elige Generic -> MS Publisher Imagesetter.

Paso 7: Prueba de Impresión
Imprime un archivo desde Windows usando la impresora vinculada.

En la terminal de Oracle Linux, verifica que el archivo se generó:

Bash
ls -l /var/spool/cups-pdf/ANONYMOUS/
